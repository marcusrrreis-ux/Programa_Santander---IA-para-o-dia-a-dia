# Template: O Segredo de um Bom Pedido à IA

A estrutura das Aulas para qualquer pedido: contexto, instrução, objetivo e formato.

## Modelo

Copie pelo botão no canto do bloco e troque cada pergunta entre colchetes pela sua resposta.

```text
CONTEXTO
[O que a IA precisa saber para entender a situação? A identificar o programa que gera os documentos de comunicação de uso. No banco de dados deste programa há três status para os documentos: Cancelado, Cadastrado e Atendido. Sendo que: Cancelado são documentos inutilizados, Os Cadastrados são documentos que foram enviados para os respectivos fornecedores e aguardam o envio das respectivas nostas fiscais de venda para serem anexadas e Atendido são os decumentos que as Notas Fiscais de vendas já foram recebidas e anexadas. ]

INSTRUÇÃO
[O que você quer que a IA faça? Gera relatório das Comunicações de Uso com a sutuação "Cadastrada". Como: Acessar a opção de relatório => Botão pesquisar => Usar os parâmetros: ipo de saída: Comunicação de Uso/ Sutuação: Cadastrada e então executar o Botão BUSCAR.]

OBJETIVO
[Por que você precisa disso? Para saber quais empresas estão pendentes de enviar notas fiscais de venda e quantas conunicações estão pedentes por empresa, bem como as mais "antigas" que estão pendentes.
O que deve acontecer depois? Eu envio a relação de pendencias para os repectivos fornecedores providenciarem a emissão das notas fiscais. ]

FORMATO
[Como a resposta deve ser entregue? Relatório em formato de pasta de Excell.]


## Teste do Estagiário

Se você entregasse esse pedido para uma pessoa nova no time, ela teria contexto suficiente para executar sem precisar adivinhar?

Se a resposta for "não", melhore o pedido.
